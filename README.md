# Class Schedule Viewer

A colorful browser-local tool where students can view and edit their class schedule. All data stays in the browser using localStorage — refresh and your classes are still there. Built with Vite and React, styled with a premium/editorial design approach with colorful cards, generous spacing, and gradient accents. No login, no backend, no database. Just open it and manage your schedule.

## Tech Stack

- Vite
- React
- Plain CSS
- localStorage

## How to Run Locally

```bash
npm install
npm run dev
```

## Build Shape

Browser-local tool — all data stored in localStorage (key: `class-schedule`). No server, no auth, no database.
